# BT Destek Öğrenimi

Bu repository, Bilgi İşlem Destek Personeli ve Help Desk alanında kendimi geliştirmek amacıyla oluşturduğum eğitim notlarını ve troubleshooting çalışmalarını içermektedir.

## Tamamlanan Dersler

### 01 - Yardım Masası Temelleri
- Belirti ve sebep ayrımı
- Katmanlı arıza analizi
- Teşhis koyma mantığı

### 02 - Windows Önyükleme İşlemi
- PSU
- BIOS / UEFI
- POST
- Boot Manager
- Kernel
- Driver
- Service

### 03 - Süreçler ve Hizmetler
- Process
- Service
- DHCP Client
- DNS Client
- Print Spooler
- Windows Update

## Hedef

Bilgi İşlem Destek Uzmanı olarak çalışabilecek seviyeye ulaşmak ve tüm öğrenme sürecini dokümante etmek.
